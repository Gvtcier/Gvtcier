# GvFont — Gv 专属字体系统

Gv 专属字体的绘制、存储与生成工具链。点阵尺寸固定 **10×10**(宽×高)。

## 目录结构

```
GvFont/
├── README.md        本说明
├── gvfont_paint.py  字体绘制 GUI 工具(Python + tkinter)
├── font/            绘制导出的点阵 txt(A.txt、B.txt …)
└── *.gvf            编译生成的字体文件(由编译工具产出)
```

## 点阵 txt 格式

每画完一个字母,保存为 `font/<字母>.txt`:

- 文件含 **10 行**,每行 **10 个字符**
- `0` = 黑色(空)、`1` = 白色(笔画)
- 每行以换行结束,文件无额外头部

示例(font/A.txt):

```
0000000000
0001100000
0011010000
0110011000
0111111100
0110011000
0110011000
0110011000
0000000000
0000000000
```

## .gvf 格式草案(编译工具产出)

类似 ttf 的 Gv 专属文字皮肤,由编译工具把 font/*.txt 合并生成。草案:

| 段 | 内容 |
|---|---|
| 魔数 | `"GVF1"`(4 字节) |
| 头部 | 宽 10、高 10(各 1 字节)、字符数 N(1 字节) |
| 字符表 | N × (码点 1 字节 + 点阵 100 字节) |
| 点阵 | 每字节一位:1 = 白(笔画)、0 = 黑(空),行优先,高位在前 |

- 码点:**A-Z = 0x41-0x5A、a-z = 0x61-0x7A,共 52 个字符**
- 文件大小 = 4 + 3 + N × 101 字节

格式定型待字体绘制完成后由编译工具落地。
