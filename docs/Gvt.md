# Gvt 版本控制

Gvt 是版本控制工具，位于 Gvt\ 目录，源码为 Gvt\src\gvt.c。

## 技术线：仓库结构

```
仓库/
├── .gvt/            版本数据库(初始化时创建)
│   ├── 索引         已添加文件的清单(jia 写入)
│   └── 提交历史     每次 tijiao 追加一条记录
└── PaiChu.gvt       排除文件(每行一个要忽略的名称)
```

- **索引**:`jia` 将文件或目录(递归)登记进索引,提交时以索引为快照范围
- **提交**:`tijiao -m` 读取索引,生成快照记录追加到历史;`rizhi` 按时间倒序展示
- **排除**:`PaiChu.gvt` 中的名称不进入索引,用于忽略产物与临时文件

## 命令

- chushi 初始化仓库，创建 .gvt 目录
- jia <文件或目录> 添加文件到索引，目录会递归添加
- tijiao -m <消息> 提交变更
- rizhi [-n <数量>] 查看提交历史
- bangzhu 查看帮助

## 排除文件

PaiChu.gvt 列出不需要提交的文件或目录，每行一个名称。目录按名称排除整个目录。

## 使用

初始化后添加并提交：

```
gvt chushi
gvt jia .
gvt tijiao -m "更新说明"
gvt rizhi
```

## 数据流

```
工作区文件 ──jia──▶ 索引(登记)
索引 ──tijiao -m──▶ 提交历史(快照)
PaiChu.gvt ──▶ 过滤(jia 时跳过)
```
