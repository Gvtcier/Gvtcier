# Gv-2280 编码

Gv-2280 是字符编码,变长结构,单字节区与双字节汉字区。

## 结构

单字节区(0x00-0x7F):

| 码点 | 内容 |
|---|---|
| 0x00-0x1F | 控制字符 |
| 0x20-0x39 | 大写字母 A-Z |
| 0x3A-0x53 | 小写字母 a-z |
| 0x54-0x5D | 数字 0-9 |
| 0x5E-0x7E | 空格与符号 |

双字节汉字区(0x80 xx):GB2312 全部 6763 汉字按区位顺序编码,首字 啊 为 80 00,末字 齄 为 9a 6a。

## 排序

编码值按字符优先级递增:控制字符、大写字母、小写字母、数字、符号、汉字。汉字内部按 GB2312 区位顺序。

## 内核使用

内核默认使用 Gv-2280 编码输出,GB2312 用于兼容。

- 文本输出:串口输出按 Gv-2280 编码,单字节字符 1 字节,汉字 2 字节
- 键盘输入:按键转换为 Gv-2280 码点
- 文件内容:文件写入与读取支持 Gv-2280 编码
- 编码表:6763 汉字表位于内核 io 模块
- 兼容:GB2312 用于文档与外部工具
