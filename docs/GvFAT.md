# GvFAT 文件系统

GvFAT 是 Gvtcier 自研的文件系统,面向块设备(512 字节/块)实现,提供多级目录、元数据、健壮性与扩展 API。驱动位于 `Kernel/Drive/gvfat/`,以独立用户态驱动形式运行,通过磁盘读写接口访问 AHCI/ATA 设备。

## 技术线

### 整体架构

GvFAT 采用**超级块 + 位图 + 目录区 + 数据区**的经典分区布局,所有区域以块(512B)为单位对齐:

```
块 0        超级块(魔数 GvF + 布局参数)
块 1..      位图区(每块 1 位,标记数据块占用)
..          根目录区(固定 32 块)
..          数据区(文件与子目录内容,连续块分配)
```

- **超级块**:块 0,魔数 `GvF` + 位图/目录/数据区起始与总量参数,`mount` 时读取并校验
- **位图区**:块粒度分配,`bitmap_get/set` 按块查询与置位,fsck 依此做一致性校验
- **目录区**:根目录固定 32 块,子目录以数据块存储目录项
- **数据区**:文件内容与子目录,`find_free_run` 找连续空闲块,写入按需扩展并预分配

### 目录项布局

目录项 40 字节,关键偏移:

| 偏移 | 字段 | 说明 |
|------|------|------|
| 0-11 | 文件名 | 12 字节,`NAME_LEN` |
| 12-19 | 起始块 | 8 字节,48 位寻址支持大容量盘 |
| 20-27 | 大小 | 8 字节 |
| 28-31 | 块数 | 4 字节 |
| 32 | 属性 | 位 0 目录 / 位 1 只读 / 位 2 隐藏 / 位 3 符号链接 |
| 33-34 | 修改时间 | 秒/2 存储,精度 2 秒,覆盖 24 小时 |
| 35-36 | 创建时间 | 同上 |
| 37 | 属主 | 用户 ID(权限校验用) |
| 38 | 属组 | 组 ID |

- **时间戳**:`gvfat_set_time(min)` 注入时钟,内部 ×60 转秒,存储 (秒/2),2 字节覆盖全天
- **权限**:`CURRENT_UID==0` 视为超级用户可写;否则仅属主可写,只读位(位 1)阻止写入
- **符号链接**:属性位 3,数据块存目标路径,解析时最多跳转 4 次防环(`resolve_path_with_links`)

### 路径解析

路径按 `/` 分割为段(`split_path`,最多 8 段,每段 ≤12 字节),`resolve_dir` 逐级下钻目录:

```
resolve_path(parts) → 逐级 find_entry → (起始块, 大小, 块数, 属性, LBA, 槽位)
```

- 目录块带缓存(`CACHE_LBA/CACHE_BUF`,1 块),减少重复读盘
- 符号链接目标作为完整路径重新解析,最多 4 跳

### 读写与分配

- **写入扩展**:`gvfat_write` 按需扩展,新分配块数 = 需求 + 8(预分配),`find_free_run` 找连续空闲;已有数据先复制到新块再释放旧块
- **批量读取**:`gvfat_read` 每次最多读 8 块(4096B),减少 syscall 次数
- **追加**:`gvfat_append` 定位到文件末尾再写入
- **截断**:`gvfat_truncate` 释放多余块并更新目录项

### 健壮性

- **fsck**:遍历目录树跟踪引用块(`TRACK` 数组),与位图对比,报告孤儿块(位图占用无引用)与丢失块(有引用未占用)
- **坏块标记**:`gvfat_mark_bad` 将坏块在位图中置位,后续分配跳过
- **文件锁**:`gvfat_lock/unlock` 置位/清除句柄锁,锁定时读写拒绝(互斥)
- **目录变更事件**:`event_log` 环形日志(16 条),记录创建/写入/删除/截断/链接/建目录,`event_count/event_dump` 查询

### 多盘挂载

`mount(base_lba)` 以块号偏移挂载,同一驱动可同时管理多块盘;`init()` 默认挂载盘 0。

## 驱动接口

| 函数 | 说明 |
|------|------|
| gvfat_open | 打开文件(支持路径),不存在时创建 |
| gvfat_read | 从当前位置读取(批量 ≤8 块) |
| gvfat_write | 写入数据,按需扩展(预分配) |
| gvfat_close | 释放句柄 |
| gvfat_mkdir | 创建子目录(支持路径) |
| gvfat_list | 列出目录内容 |
| gvfat_remove | 删除文件或空目录(支持路径) |
| gvfat_append | 追加写入(定位到末尾) |
| gvfat_truncate | 截断文件到指定大小 |
| gvfat_stat | 查询文件状态(类型/大小/块数) |
| gvfat_ln | 创建符号链接 |
| gvfat_link | 创建硬链接(共享数据块) |
| gvfat_lock / gvfat_unlock | 文件锁(读写互斥) |
| gvfat_setuid / gvfat_setgid | 设置当前用户/组 |
| gvfat_chown | 修改文件属主/属组 |
| gvfat_fsck | 位图一致性校验 |
| gvfat_mark_bad | 标记坏块 |
| gvfat_set_time | 设置时钟(时间戳来源) |
| event_count / event_dump | 目录变更事件查询 |
| mount | 挂载指定盘(多盘,base_lba 偏移) |
| init | 初始化,挂载盘 0 |

## 工具

`gvtcier-gvfats` 生成 GvFAT 卷镜像:

```
gvtcier-gvfats <out.img> [blocks]
```

默认 16384 块。文件句柄上限为 8(`MAX_FILES`)。
