# GvFAT 文件系统

GvFAT 是 Gvtcier 使用的文件系统,支持多级目录、元数据、健壮性与扩展 API。

## 功能

- 文件读写,打开不存在的文件时自动创建,写入按需扩展
- 多级目录树,路径解析(`a/b/c`),目录遍历
- 元数据:创建/修改时间戳(秒级)、目录/只读/隐藏属性
- 健壮性:位图一致性校验(fsck)、坏块标记
- 性能:目录块缓存、写入预分配、批量读取
- API:追加写、截断、状态查询、多盘挂载
- 文件句柄上限为 8

## 磁盘布局

| 区域 | 说明 |
|------|------|
| 超级块(块 0) | 魔数 HWJ + 位图/目录/数据区布局参数 |
| 位图区 | 每块 1 位,标记数据区块使用状态 |
| 根目录区 | 固定 32 块,存放根目录项 |
| 数据区 | 文件与子目录内容,连续块分配 |

目录项 32 字节:文件名(16)+ 起始块(4)+ 大小(4)+ 块数(3)+ 属性(1)+ 修改时间(2,秒)+ 创建时间(2,秒)。时间戳以秒/2 存储,精度 2 秒,覆盖 24 小时。

## 工具

`gvtcier-gvfats` 生成 GvFAT 卷镜像:

```
gvtcier-gvfats <out.img> [blocks]
```

默认 16384 块。

## 驱动接口

| 函数 | 说明 |
|------|------|
| gvfat_open | 打开文件(支持路径),不存在时创建 |
| gvfat_read | 从当前位置读取(批量) |
| gvfat_write | 写入数据,按需扩展(预分配) |
| gvfat_close | 释放句柄 |
| gvfat_mkdir | 创建子目录(支持路径) |
| gvfat_list | 列出目录内容 |
| gvfat_remove | 删除文件或空目录(支持路径) |
| gvfat_append | 追加写入(定位到末尾) |
| gvfat_truncate | 截断文件到指定大小 |
| gvfat_stat | 查询文件状态(类型/大小/块数) |
| gvfat_fsck | 位图一致性校验 |
| gvfat_mark_bad | 标记坏块 |
| gvfat_set_time | 设置时钟(时间戳来源) |
| mount | 挂载指定盘(多盘) |
| init | 初始化,挂载盘 0 |
